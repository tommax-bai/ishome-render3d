# 真户型基准（用户的测试户型，2026-09-02 起为本线的基准数据）

**基准值（用户裁决，《拍板清单》§〇 末条带原话）**：建筑面积 138 ㎡、得房率 80% → 套内 110.4 ㎡。

| 文件 | 是什么 |
|---|---|
| `几何产物.json` | aipipe `floorplan-geometry` 对测试户型图的真跑产物：82 段墙、59 段真外轮廓、19 个洞、7 间房。**只有比例没有绝对尺寸**，尺子由面积反推 |
| `design-package-真值138.json` | 按真值 138 ㎡ 组的 render3d 输入包。家具/材质为空（上游不给）、高度整段不写（吃常规住宅 mock 档位）、一台揭顶机位 `pitch −52° / yaw 35° / fov 45°` |
| `底渲-cam-bird-dollhouse/` | 那台机位的四路底渲 + 深度/遮罩的 8-bit 可视化。**注意：这批是按 114 ㎡ 那版尺子渲的**（9-01 夜，真值拍板之前），也是噪声底 0.1718 与全部方差实验用的那批条件图。**做可比实验就用这批，别重渲**——换尺子只改绝对尺度，图上的形状和比例不变，但重渲后 geometry 一路会带上 9-01 夜之后的观感改动（超采样/SSAO/阴影），条件图就不同了 |

重渲（会得到新观感的 geometry，line/depth/mask 三路逐字节不变）：
```bash
uv run render3d --design _iteration/真户型-基准/design-package-真值138.json -o /tmp/out/ --width-px 1280 --height-px 960
```

原始户型图（`test.png`）在用户桌面，不进仓。

## 2026-09-05 追记：基准换成 16 洞产物（aipipe c9fc00c）

上面那份 `几何产物.json`（19 洞）是 aipipe `994e66c` 之前的产物：路口那坨投出了 x≈830 / 885 / 1063
三条假墙线，留档里 **#3 / #4 / #5 / #7 四个洞落在假墙线上、不是洞**（旁边贴着平行墙 100%，见 aipipe
`_iteration/run-2026-09-05-opening-kind/run.md` §三 3.1）。本仓此前把它们当内墙洞猜成门、起了体、补了过梁。
洞没有类型字段，19 个全按外墙＝窗 / 内墙＝门猜。

| 文件 | 是什么 |
|---|---|
| `几何产物-16洞-c9fc00c.json` | aipipe `c9fc00c` 对同一张图的产物（从 aipipe `_iteration/run-2026-09-05-opening-kind/geometry-138.json` 逐字拷来）：58 段外轮廓、74 段墙（带 `bands` 分段墙带）、**16 个洞（每个带 `kind` / `kindEvidence`，覆盖率 15/16）**、7 间房、`cellCoverageRatio` 0.9814 |
| `design-package-真值138-16洞.json` | 按它组的输入包：`plan` 逐字取产物 `geometry` 段，尺子（138 ㎡ / 80%）与揭顶机位照旧那份。`revisionId` 改为 `real-test-geometry-c9fc00c` |

**对此前实验的影响**：噪声底 0.1718、方差实验、控制通路调研、失效清单取样用的都是 19 洞那批条件图
（`底渲-cam-bird-dollhouse/` 与各 run 目录里的图）。那些结论不依赖洞数（它们比的是同一批条件图之间的差），
**但条件图与尺子基线从这天起换了**：尺子只差万分之一（假洞不影响外轮廓面积），条件图不同——少了四个假洞
的门洞槽与过梁、多了洞口类型。新旧条件图不许混在一次比较里；要与 9-05 之前的数可比，仍用旧那批图。
新基线的 8 台机位三路图在 `_iteration/run-2026-09-05-opening-kind-consume/`。

旧文件不删：它们是此前实验的证据。
