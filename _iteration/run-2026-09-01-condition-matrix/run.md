## 本来要回答什么

底渲四路（几何／深度／线稿／遮罩），哪种组合喂给写实化，几何锁得最死？

## 答案：**测不出**。噪声压倒了组间差异

先量噪声底：同一条件图（`geometry + line`，一字不差）连跑 3 次——

| 重跑 | 分数 | 视觉核对 |
|---|---|---|
| 跑一 | 0.2197 | 左侧凹字形轮廓、房间分隔都对 |
| 跑二 | 0.1201 | — |
| 跑三 | 0.0479 | **整个左侧凹字形轮廓消失**，退化成简单矩形 |

**极差 0.1718 ＝ 噪声底。** 而矩阵六组的分数是：

| 组合 | 分数 | 样本 |
|---|---|---|
| ① 仅 geometry（基线） | 0.0371 | 1 |
| ② geometry + line | 0.1292（均值，三跑） | 3 |
| ③ geometry + depth可视化 | 0.1426 | 1 |
| ④ geometry + line + depth可视化 | 0.0202 | 1 |
| ⑤ 仅 line | 0.0286 | 1 |
| ⑥ geometry + line + mask可视化 | 0.1989 | 1 |

**逐对核过：除 ④对⑥（差 0.1787，压线超过噪声底 0.1718）外，两两差距全部小于噪声底
＝测不出差别。** 那唯一一对也只是压线且各只有 1 个样本，不足以定论。
按《纪律·阈值有数据才定》，**不排名次**。

独立佐证：协调者另做的对照（同一"有家具"条件图两次真跑）同输入极差 0.0821，
同一现象。两组独立证据指向同一结论。

## 值得记一笔但数字上不能实锤的一件

`geometry + line + depth`（0.0202）是矩阵里视觉上**完全丢失真实户型左侧凹字形轮廓**、
退化成矩形的那张，比只用 geometry 的基线还差。"多给一路条件图不一定更好"值得记。
**但**：`geometry + line` 三跑里最差的那次（0.0479）**也**丢了同一个特征、同一种失败
形态——所以不能排除它只是撞上了本来就存在的高方差坏结果。**视觉上可疑，数字上不能证实。**

## 度量怎么立住的（以及一个没绕过去的坑）

位置 + 走向双重判据：写实化结果降采样回线稿分辨率（低通掉材质纹理伪边）→ Sobel →
非极大值抑制细化成脊线 → 取最强 10%；命中 ＝ 位置在 2 像素内**且**走向夹角在 4° 内。

**只判位置量不出东西**：把线稿平移 50~200 像素，分数几乎不变，个别还更高。
原因是户型俯视图是等轴测画法，边几乎只落在两个典型方向上且在画面里近似均匀分布——
"附近随便有条边"跟"线稿挪到哪儿"几乎无关。加了走向匹配后**平移对照依然不灵**
（这是这类图的固有性质，不是 bug），改用**旋转 90°** 作对照才生效：0.0237，
比坏图再低 36%，只有好图的 27%。

**这条限制要跟着度量走**：它测得出"墙转了向、房间没了"，测不出"整体平移"。
