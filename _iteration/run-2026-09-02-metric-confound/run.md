# 真跑记录：保真度尺子量的不只是几何（2026-09-02 早）

> **写完不改**。它修正 `run-2026-09-01-condition-matrix` 里那把尺子的解释，以及
> `run-2026-09-01-variance-knobs` §五那条"裸壳假说"。

## 起因

用户看报告问："0.0x 是不是失真很严重？"——答这个问题时拿**底渲自己量自己**，
结果翻出一个此前没查的混淆。

## 数

| 被量的图 | 分数 |
|---|---|
| 底渲 `geometry.png` 对自己的 `line.png`（几何**完全正确**） | **0.0607** |
| 今天最好的生成图（裸壳形态） | 0.2391 |
| 今天最差的生成图（富装形态） | 0.0393 |

**几何完全正确的底渲，分数比最好的生成图低四倍。**

## 为什么

尺子的命中判据是"线稿的边像素附近、生成图上有没有一条走向一致的强边"。
底渲是平色的——两面同材质的墙贴在一起没有可见交界，Sobel 找不到边，线稿的线压上去就是"未命中"。
生成图有阴影、有材质变化，同一处反而有边。

**所以这把尺子量的是"墙线在图上看不看得见 且 位置对不对"，两件事混在一起。**
它的分数不是保真度百分比，满分远不是 1.0，只能横向比。

## 这动摇了两件已记的东西

1. **"裸壳假说"**（`variance-knobs` §五）：裸壳分数高，**可能不是几何更准，而是没家具挡着、墙都露着、好量**。
   这条假说的证据现在要打折，要证实它得先把遮挡剔出去（比如只在遮罩标为"墙"且无家具覆盖的区域内计数）。
2. **门禁的阈值**：若按裸壳的分数定线，**正常摆满家具的图会被系统性误判成不合格**——
   家具遮住墙是合法的，不是失真。门禁的度量要么剔遮挡，要么按输出形态分档定线。

## 没变的

- 方差本身的结论不变：同一份输入三跑三套房子，这是看图看出来的，不靠这把尺子。
- 噪声底 0.1718 作为"同尺子同输入的散布"仍成立；但**它是这把尺子的噪声，不纯是模型的噪声**——
  遮挡随家具摆放随机变化，也贡献散布。
- "测不出整体平移"那条限制不变，本条是在它之外再加一条。
