# 真跑记录：方差压不压得下去——探旋钮（2026-09-01 深夜）

> **写完不改**——它是判据的证据（《纪律·日志正文不改》）。
> 前情：`run-2026-09-01-fidelity-variance`（方差存在）与 `run-2026-09-01-condition-matrix`（噪声底 0.1718，条件图组合测不出名次）。

## 问题

写实化这条通路的输出方差，能不能靠参数或提示词压下去？压不下去，门禁就是唯一的路。

## 一、`seed`：发了没用

网关对 `realism-pass.default` 单独关了 `drop_params`，非标准参数理论上能透传。
用**同一个 seed、同一份条件图、同一段提示词连跑两次**：

- 保真度分数 0.0128 → 0.1548（差 0.1420，与噪声底 0.1718 同量级）；
- SHA256 不同，419KB vs 282KB；
- 降采样到同尺寸逐像素比对：均值绝对差 47.2/255，**72.7% 的像素差超过 10 级**——不是编码噪声，是两张结构不同的图。

请求本身 HTTP 200、`input_images=2` 正常——**只看"没报错"会误判为支持**。
字段要么被静默丢弃、要么被接受但不起决定性作用；**两种情况对产品结论是一回事：发它换不来可复现性。**

## 二、`guidance_scale`：明确不支持

HTTP 400，报文写着"the parameter `guidance_scale` ... is not supported by the current model"。
很快返回，没浪费一次完整生成。**说明网关不是来者不拒**——这反过来提高了"其他参数被接受"这件事的信息量。

## 三、提示词约束：两条改法都测不出差别

约束句里的户型事实**从 `scene-package.json` 读**，不是编的（7 个房间名各一次；地面 86.7㎡ / 外接矩形 119.8㎡ ≈ 0.72，外轮廓有实打实的缺角）。

| 改法 | 三连跑分数 | 极差 |
|---|---|---|
| 一、房间数 + 外轮廓显式约束句 | 0.0658 / 0.0393 / 0.2317 | 0.1924 |
| 二、点明线稿是墙体轴线权威源 | 0.2165 / 0.2120 / 0.0303 | 0.1862 |

两条极差**都没有小于噪声底 0.1718**。按《纪律·阈值有数据才定》：**测不出差别，不排名次。**

## 四、`strength`：方向有意思，但仍测不出

前一轮只跑了 1 次、如实标成"不知道"。本轮补做因果测试：

| 条件 | 三连跑分数 | 均值 | 极差 |
|---|---|---|---|
| `strength=0.98` | 0.2339 / 0.2391 / 0.1094 | 0.194 | **0.130** |
| 不给 strength（矩阵那组） | 0.2197 / 0.1201 / 0.0479 | 0.129 | **0.172** |

均值更高、极差更小，**方向有利**；但两组分布重叠（0.1094 落在对照组区间内），n=3 对 n=3，
**按噪声底判据只能写"测不出差别"**。另跑一次 `strength=0.25` 得 0.0393。

## 五、观察到的双模态（值得记，但不是定律）

这条通路的输出有两种形态：**裸壳**（无家具、材质近乎不渲，像素模型套件）与**富装**（满屋陈设、材质完整）。
今天量到的对应关系：

- 裸壳：0.2339、0.2391 —— 今天所有样本里最高的两个
- 富装：0.1094、0.0393

**假说：模型往图里加的东西越多，几何改得越多——观感与保真度此消彼长。**
**但这不是定律**：`家具对照/写实-光壳.png` 是一张满屋陈设的富装图，却拿了 0.2092（很高）。
所以只能说"两者相关"，不能说"富装必然低保真"。**样本量不够，别当口径用。**

## 六、结论

**在这次预算内探到的手段都不管用**：`seed` 发了没用、`guidance_scale` 被拒、两条提示词约束测不出差别、
`strength` 方向有利但测不出。**门禁（生成 → 量分 → 不过线重出／转兜底）大概率是现实里唯一能落地的路。**

**但这不等于穷尽了可能性。** 两条值得后续补的：
1. `strength` 加大样本量（每档 n≥5）再判——它是唯一方向有利的旋钮；
2. 双模态那条假说——如果"裸壳模态保真度更高"站得住，那门禁之外还有一条路：
   **主动往裸壳那一端调，再用确定性手段补观感**。这条要先证伪或证实那个假说。
