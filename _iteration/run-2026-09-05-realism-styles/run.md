## 看图

**几何（判据①）**
- 揭顶四张：同一套房、同一朝向、同一房间划分，外轮廓、内墙、每扇窗的位置都对上；叠红后线压合，没有哪面墙搬家、没有房间合并/拆分。风格内（nordic seed1 对 seed2）也一样。
- 主卧三张：同一角度、同一道凸出的隔墙、左墙同样三个洞口；叠红后洞口边、隔墙边、地脚线都压在渲染边上。
- 变的是洞口的**读法**不是位置：中间那个窄洞 modern 画成落地窗（有外景）、nordic 画成灰蓝门扇、cream 画成一道窄缝；左边那个 modern/nordic 是门、cream 是开着的金属门扇（露外景）。这是上游 9 个补洞全标门、门窗不分那件旧事（`run-2026-09-05-control-sketch-realism/run.md`），不是风格改了几何。

**风格（判据②）**
- modern（基线）：暖白墙、浅橡木地板、黑窗框黑门扇、有一块暖色日光斑。
- nordic：墙更白、地板更浅偏灰白、门扇与窗框成灰蓝色、整体是均匀的冷白漫射光，没有日光斑；揭顶图背景也被拉亮。seed2 比 seed1 更白、灰蓝更饱和，风格方向一致。
- cream：墙奶油色、主卧地面换成大块暖米色地砖（揭顶图里过道是砖、房间里还是木地板）、门扇/门框是香槟金金属、整体暖黄光；揭顶图的墙顶剖切面被渲成深棕色（modern 是黑、nordic 是白）。
- 三种风格一眼能分开，差别都落在墙、地、门窗材质与光上，正是模板那一句写的东西。

**无陈设（判据③）**
- nordic 三张：家具 0 件；残留只有门把手（门扇自带的五金，不算）。
- cream 主卧：家具 0 件；右侧门洞里有一根细杆状物（疑似小件，1）。
- **cream 揭顶：右上房间一株绿植 + 一件橙棕色小物；右下房间地面多出一块木色抬高的平台/台阶（沿墙一整条，带暖光）；卫生间门口一个深色小件。** 这是 5 张里唯一一张陈设句没完全压住的——同一控制稿、同一 seed 下 modern 与 nordic 都是空房，所以是奶油风那句词带出来的（"暖光""圆润"这类词更容易把模型往"有生活气的样板间"带），不是控制稿的问题。

## 分数怎么读

主卧 nordic 0.1723 对 modern 0.5547，看图几何却是一样的。`debug-主卧-…png` 里能看到原因：nordic 白墙白顶、地板浅色，墙顶线和地脚线是白对白的低反差边，NMS 后进不了最强 10% 脊线；那 10% 的配额被地板木纹吃掉了（右图地面一片蓝）。cream 的墙顶线有一道深色缝、地砖对墙有色差，边强，所以分数没掉。

两个反证试过：把百分位从 90 降到 70，nordic 只从 0.17 到 0.20（不是"边稍弱"）；把容差从 2 px 放到 8 px，nordic 0.17→0.42、modern 0.55→0.80——有一点门框相对洞口线的几像素偏移，但主体是边根本不够强。转 90° 对照 0.0118，度量本身还在工作。

结论：**这把尺子跨风格不可比**——上次说的"只能同形态横向比"要再收一格，同形态还得同风格。它量的是"控制稿线所在处有没有一条够强的边"，而"够不够强"由风格的材质反差决定。门禁若按 modern 的分数带定阈值，nordic 会全被拦下；几何对不对这件事，这一轮是靠叠红看出来的，不是靠数。

## 我的判断（不是裁决）

- "换风格只换一段文字、几何不动"这条**成立**：五张里没有一张墙或洞口位置随风格变。
- `nordic-light` 可以作候选进模板目录：两 seed 都听话、风格方向稳。
- `cream-warm` 现在这版不建议直接进：揭顶图 4 处陈设/平台残留，得改词再跑（比如去掉"圆润""暖色调柔和光线"这类氛围词，换成具体材质词）才好说。
- 门禁阈值不能跨风格共用，这条要带回中控仓门禁方案。
