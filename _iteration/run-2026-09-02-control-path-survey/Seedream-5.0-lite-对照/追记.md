# 追记：换 Seedream 版本有没有用（2026-09-02 下午）

> 用户问"能不能换更高阶的 Seedream 版本"。本目录是对照跑，`run.md` 正文不动。

**我们用的是 `doubao-seedream-5-0-pro-260628`，这已经是方舟里最高一档。** 方舟图片生成 API 今日只有四个版本：5.0 pro、5.0 lite、4.5、4.0，四个共用一张参数表（`image`＝参考图片，无结构控制参数）。

| 版本 | 结果 |
|---|---|
| `doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828` | 账号未开通（HTTP 404 `ModelNotOpen`），各发 3 次未计费 |
| `doubao-seedream-5-0-260128`（5.0 lite） | 3 跑成功，42.6 / 39.0 / 48.2 s，2304×1728 |

5.0 lite 三跑（同一份 geometry+line 条件图、同一段提示词、直连方舟）：分数 0.1658 / 0.1122 / 0.1168，极差 0.0536。
**极差小不作数**——`montage-叠线.png` 下排把线稿叠红：run2、run3 整栋房子相对线稿**平移**了，隔墙划分三跑各不相同
（run2 上部并成大开间摆沙发，run3 上部摆了餐桌）。尺子"测不出整体平移"那条已知限制在这里正好中招，所以以看图为准：**还是三套房**。

结论：换 Seedream 版本换不来控制通道，机制没变（参考图）。费用：lite 3 张（单价按方舟页面），404 的 6 次不计费。
