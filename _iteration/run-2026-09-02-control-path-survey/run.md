- 看图（`montage.png`、`overlay-run1.png`）：五张同一套房子，墙线压红线；画质差（木纹桌面上的模型、材质糊）——那是 SD1.5 + 512×384 的事，与机制无关。
- **分数绝对值不能与万相那栏比**：出图 512×384 被尺子放大到 1280×960 再提边，边缘糊掉、命中率天然偏低（尺子限制"只能同输出形态横向比"在此再次成立）。
