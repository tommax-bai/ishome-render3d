## 做了什么

1. **契约对面**：`PlanOpening.kind`（闭集 `door | window | passage | entry-door | unknown`，与上游逐字一致；
   旧值 `pass` 改名 `passage`，`HeightRules.pass_height_m` 字段名不改）、`kindEvidence`；`FloorplanGeometry.
   openingKindCoverageRatio`；`PlanWall.bands`（同一份产物里 `994e66c` 起带的分段墙带，**只收不消费**，
   起体仍按整条线一个厚度）。上游没给 `kind` 的旧产物读进来是 `unknown`，不是门。
2. **起体先读 `kind`**：`mesh.resolve_opening_kind` 一处——上游给了就照上游（来源 `upstream`），`unknown` 才按
   档位猜（来源 `guessed`）。`passage` 落地、无窗下墙、洞高按过口档位；`entry-door` 按门起体、种类照写。
   场景包新增 `openings[]`（每洞：下标、最终 kind、来源、落没落到墙上）、`guessedOpeningCount`、
   `guessedOpeningIndices`；CLI 与 scene-compile 回执都把"按档位猜的洞"打出来。
3. **控制稿按最终 kind 画**：门与入户门一条斜线、窗一个十字、过口无符号；种类从场景包洞口表读，
   补出来的洞（落在墙段空隙里、没有套框）不再靠"有无窗下墙"猜门窗。老场景包（没有洞口表）退回按网格 id 读。
4. **基准换成 16 洞**：`_iteration/真户型-基准/几何产物-16洞-c9fc00c.json` + `design-package-真值138-16洞.json`
   （尺子、机位照旧），README 追记旧 19 洞里 4 个假洞与影响；旧文件不删。本目录：8 台机位重渲 geometry / line /
   sketch 三路（1280×960，机位包 `design-package-真值138-16洞-roomcams.json`，几何换成 16 洞、7 台 room 机位同
   9-04 那份）、`montage-19洞旧控制稿-vs-16洞新控制稿.png`（左＝`run-2026-09-05-control-sketch/` 那批 19 洞控制稿，
   右＝本批）、`重渲与拼图.py`。
5. 测试 20 条新增（`tests/test_opening_kind.py`）：kind 缺省与旧值拒收、猜法字段不许 unknown/entry-door、先读后猜、
   猜的计数、过口不补窗下墙（切出来的与补出来的两种形态）、入户门按门起体、控制稿三种符号各出现、判成过口的稿是判成
   门的稿的子集、补出来的过口按洞口表画、洞口表与网格对不上就炸、旧 19 洞包全部走猜法、新 16 洞包全链渲通。
   全套：ruff / mypy strict / import-linter 2 契约 / pytest **206 全过**。

## 没做的（写清哪件、为什么、时点）

| 件 | 为什么没做 | 时点 |
|---|---|---|
| `PlanWall.bands` 按段厚度起体 | 本批只做洞口类型；收下字段是为了新产物读得进（`extra=forbid`），起体仍按整条线一个厚度 | 用户拍"墙按段起体"那一批 |
| `unknown` 的控制稿符号另画一种 | 今天 `unknown` 在编场景包时已按档位猜成门或窗，控制稿画的是猜出来那一种；另画一种"不定"符号是新画法，没有数据说通道认得它 | 用户拍 |
| 管井小门（#3）猜成窗 | 猜法是"外墙＝窗"，上游说它"不是户内的门窗"；本批只把"猜了"计数并写明，没改猜法（改了就是本仓替上游定类型） | 上游给管井/设备位一类的 kind，或用户拍猜法 |
| 厨房机位 | 与 19 洞那批同样无法取景（地板占比 0.023），洞数不改它 | 取景判据或站位契约那条线 |
| 真户型上的 `passage` | 16 洞里没有过口，真图只能盖到门/窗/入户门/unknown 四种；过口只在合成小包测试里验过 | 拿到带过口的真产物（92㎡ 楼书图那份包）进本仓基准时 |
| 对着入户门的机位 | 机位包照旧那份（1 bird + 7 room 按房间名自动取景），没有一台对着入户门 | 下次加机位时 |

## 要用户拍的

1. **`unknown` 在控制稿上怎么画**：今天＝按猜出来的种类画（外墙十字、内墙斜线），场景包里标着 `guessed`。另一个选项是
   `unknown` 只画洞口轮廓不画符号（同过口），让模型自己定——哪个对写实化更好没有数据。
2. **`PlanWall.bands` 要不要消费**（按段厚度起体）：render2d 已按它画，三维今天只收不用。
3. **管井/设备位一类的洞**（上游 `unknown`、connects 为空）三维要不要起体：今天当窗起了体；不起体就是外墙上没有这个洞。
