## 看图

**几何（叠红）**
- 揭顶三张：外轮廓、内墙、每扇窗、每个门洞的红线都压在渲染边上；同一套房、同一朝向、同一房间划分，没有墙搬家、没有房间合并/拆分。三 seed 之间也一致。
- 主卧两张：左墙窗洞边、中间窄洞边、右侧门洞边、凸出隔墙的竖边、地脚线都压合；v3 配准位移 2–3 px。
- 控制稿门的斜线符号在揭顶图上留了痕：seed1 顶部过道地面一条淡淡的斜线；seed2 顶部过道地面被斜线切成木色/米色两个三角；seed3 右下房间沿斜线长出一根白色实体条。这是上一批已记的"斜线偶尔被实体化"（`run-2026-09-05-opening-kind-realism/run.md`），属控制稿符号问题，不是风格词带的，也不算陈设。

**风格（模板那句写的东西）**
- 墙面奶油白哑光：5/5 听话。
- 地面"米色哑光大板砖"：主卧 seed1 是标准大板砖（分缝清楚）；主卧 seed2 是粗糙米色板材（介于砖与木之间）；**揭顶三张主体还是木地板**——seed1 全屋木地板，seed2 左房与右下两房米色、其余木，seed3 左房与下方两房米色、其余木。地面词在揭顶视角只部分听话，第一版也是"过道是砖、房间里还是木地板"，这条跨版一致。
- 门窗框"暖白色金属"：揭顶 seed1/seed2 与主卧两张是白/浅灰框；揭顶 seed3 是深色框、墙顶剖切面也渲成黑色（像 modern 基线）。
- 光：整体暖白，没有第一版那种整屋暖黄；seed3 揭顶几个房间里有暖黄光斑。
- 背景：seed1 纯白、seed2 灰、seed3 浅灰——通路没约束背景，各 seed 自便。

## 我的判断（不是裁决）

- 去掉氛围词有用：揭顶从"1 张 4 处"到"3 张里 2 张 0 处、1 张 2 处"，主卧 2 张干净（1 件疑似是门扇形态）。方向对。
- **v2 我不建议直接转正，差一步**：nordic 转正时的样子是所跑 seed 全干净，v2 揭顶 seed3 还有 2 件，而且那两件（地毯状物、矮平台）跟 v1 带出来的东西同类，说明"奶油风格"这个风格名本身还带着一点"有生活气的样板间"的拉力——v2 与 v1 唯一共有的词就是它。
- 下一步两条二选一，都是小跑：(a) 揭顶再补 3 个 seed，看 seed3 是偶发还是 1/3 的稳定率；(b) 再改一版把"奶油风格"这个名词去掉、只留材质词（模板 id 照旧叫 cream），跑同样 5 张。我倾向 (b)，因为 (a) 就算干净也说不清 seed3 为什么脏。
- 地面"大板砖"在揭顶视角不听话是另一件事，与陈设无关，不挡转正；要不要管看用户对揭顶图地面材质有没有要求。
