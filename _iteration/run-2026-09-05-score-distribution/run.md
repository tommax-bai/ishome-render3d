## 二、分档与负对照

分档四维＝视角（揭顶/室内）× 控制稿版本（19洞线稿反色 / 19洞控制稿 / 16洞控制稿，另 19洞geometry自抽、19洞线稿(参考图通路) 各自成档）× 风格 × 陈设；对照物（sketch / line）再分列。室内档把不同房间的机位混在一档——那是任务给的维度，机位拆开的数在 §四作补充。

负对照每档取 2 张（机位尽量不同；n=1 的档取 1）：

- **错配**＝同一控制稿版本、另一台机位的稿（揭顶→客厅；客厅→主卧；主卧→客厅或书房；次卧↔书房）。
- **转 90°**＝自家稿转 90°（尺子的 `rotate90=True`）。
- 对照物种类与正常行一致（9-05 三批 sketch / line 各做一遍）。v3 的配准会把错配也抬高（它的已知限制 2），所以三列（v2、v3 原位、v3 配准）都并排报。

## 七、没做的与限制

- **v3 只搜平移**：`scale_candidates` 用默认 `(1.0,)`，csv 里 sx / sy 恒为 1.0——不是量出来等于 1，是没搜。
- **室内档把不同房间混在一档**：任务给的四维里没有机位，而 §四"按机位拆"显示同档内房间之间的差比 seed 之间的差大。本文两种切法都列，不改分档。
- **每档只有 2 张负对照**（n=1 的档 1 张），错配只有"换一台机位"一种形态，没有"同房间、墙挪了"的样本——那是门禁真正要抓的失效，仍无真跑样本，不编。
- **n<5 的档占多数**（22 行里 17 行），那些档的最小/中位/最大只是样本本身，不是分布。
- 风格一列把探针手写的"现代简约"与 imagegen 模板的 `modern-minimal` 都归成 modern-minimal，措辞不同（`提示词来源` 列分开记）；两者是不是同一形态没有证据，只是没分开。
- run2 与 run1 逐像素相同，去重后"揭顶·19洞线稿反色·默认"实际 n=3。
- 分数绝对值仍只能同档横向比：几何全对的底渲自量 v2 0.06、v3 0.07，生成图能到 0.2–0.9——尺子量的是"稿上的线处有没有一条够强的边"，不是"像不像"（v2 docstring 限制 1）。
- 耗时：157 个任务（每个 v2 + v3）5 进程并行共 270 s，单个 5–12 s；Seedream 2304×1728 缩到 1280×960 后与别的一样。
